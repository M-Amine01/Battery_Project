# Battery_Project
modern QML Battery interface ,The goal is to learn how to link QML files with C++ files.


## Requirements

- Qt 6
- Qt Quick
- Qt Quick Controls
- CMake
- A C++ compiler

![image alt](https://github.com/M-Amine01/modern-QML-thermostat-interface/blob/5828dd10d187817179033c68c096670d315b8f92/picture.png)

## How to Build

1. Clone the repository:

```bash
git clone https://github.com/M-Amine01/Battery_Project.git

```

2. Open the project with Qt Creator.
3. Configure the project with a Qt 6.8+ kit.
4. Build the project.
5. Run the application.
